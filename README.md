# ws-goalgus

Public company site for [goalgus.bg](https://goalgus.bg) / [goalgus.com](https://goalgus.com). Synced with [ws-goalgus](https://github.com/stistoyanov/ws-goalgus) via git subtree from private [api-goalgus](https://github.com/stistoyanov/api-goalgus).

Never commit `config.php`. Deploy only from `api-goalgus` (`make deploy-goalgus` on `live`).
